# Solar_System_Explorer
Интерактивная 3D-демонстрация Солнечной системы с анимацией орбит, кометами и образовательными карточками планет. Данные NASA/JPL.

🌌 Solar System Explorer

Интерактивная образовательная демонстрация Солнечной системы** — визуализация, созданная для изучения космоса. Наблюдайте за орбитальным движением всех восьми планет, сопровождайте кометы по их эллиптическим траекториям и узнавайте удивительные факты о каждом небесном теле одним кликом.

> 📡 Все астрономические данные (размеры, расстояния, орбитальные периоды) взяты из открытых источников [NASA](https://www.nasa.gov/) и [JPL Solar System Dynamics](https://ssd.jpl.nasa.gov/).

✨ Возможности

🪐 Реалистичная модель
* **Солнце** с анимацией поверхности и эффектом свечения (корона).
* **Все 8 планет** с корректными относительными размерами и цветами.
* **Орбитальное движение** с соблюдением пропорций скоростей.
* **Кометы** с хвостами и эллиптическими траекториями.

🎛️ Полный контроль симуляции
* ▶️ **Воспроизведение / ⏸️ Пауза** — управляйте ходом времени.
* ⏩ **Регулировка скорости** — от замедленного наблюдения до ускоренной симуляции лет.
* 🔍 **Масштабирование** — приближайте отдельные планеты или отдаляйтесь, чтобы увидеть всю систему.

📚 Образовательный режим
При клике на любое небесное тело открывается информационная карточка:
* 🏷️ Название планеты
* 📏 Диаметр / размер
* 🌞 Расстояние от Солнца (в а.е. и км)
* 🔄 Орбитальный период
* 🌟 Уникальные особенности и интересные факты

#🕹️ Управление

| Действие | Десктоп | Мобильные устройства |
|----------|---------|----------------------|
| Приближение / Отдаление | Колёсико мыши | Pinch (два пальца) |
| Перемещение по сцене | Зажать ЛКМ + двигать | Один палец (drag) |
| Информация о планете | Клик ЛКМ | Тап |
| Пауза / Воспроизведение | `Space` или кнопка ▶️⏸️ | Кнопка на экране |
| Скорость симуляции | `+` / `-` или слайдер | Слайдер |
| Сброс вида | `R` | Кнопка "Reset" |

🛠️ Технологии

Проект реализован с использованием современных веб-технологий:
* HTML5 Canvas / WebGL 
* CSS3 (анимации, glassmorphism для UI-панелей)
* JavaScript (ES6+) 
* Данные: JSON-конфигурация на основе каталогов NASA / JPL Horizons

 📦 Запуск проекта

1. Клонируйте репозиторий:
   
   ```bash
   git clone https://github.com/твой-username/solar-system-explorer.git

2. Перейдите в папку проекта:

   cd solar-system-explorer

3. Откройте index.html в браузере. (Если используется сборщик — добавьте npm install и npm run dev).
